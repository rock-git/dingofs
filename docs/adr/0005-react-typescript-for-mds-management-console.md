# Build the MDS management console with React and TypeScript

The MDS management console will use React and TypeScript, built with Vite, to support its planned growth from server-rendered diagnostic pages into a component-based interactive application. The initial toolchain will remain deliberately small—React, TypeScript, Vite, ESLint, Vitest, and React Testing Library—and additional state-management or UI libraries will only be introduced when concrete requirements justify them.
